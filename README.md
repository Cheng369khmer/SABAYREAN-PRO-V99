# 🎓 SabayRean Pro

Welcome to the **SabayRean Pro** repository! This is a comprehensive web platform designed to provide educational resources, courses, and integrated AI tools to assist users with coding, chatting, and image generation.

## 🚀 Features

* **AI Tools Suite:** Built-in AI assistants including AI Chat, AI Code Helper, and AI Image Generator.
* **Educational Courses:** Dedicated sections for learning and exploring various technical topics.
* **User Management:** Registration and login pages for customized user experiences.
* **Responsive Design:** Clean, modern UI built for both desktop and mobile viewing.

## 📂 Project Structure

Here is an overview of how the project files are organized:

```text
SABAYREAN-PRO/
│
├── img/                  # Image assets and logos used across the site
├── Note/                 # Project notes and documentation
├── pages/                # Main HTML pages for the website
│   ├── Ai-Tool/          # AI functionality pages
│   │   ├── ai-chat.html
│   │   ├── ai-code.html
│   │   └── ai-image.html
│   ├── Courses-Tools/    # Specific course materials
│   ├── contact.html      # Contact us page
│   ├── courses.html      # Course catalog
│   ├── login.html        # User login
│   ├── projects.html     # Showcase of student/platform projects
│   ├── register.html     # User sign-up
│   ├── services.html     # Platform services
│   └── tool-ai.html      # Main hub for AI tools
│
├── wwwroot/              # Static assets (CSS, JS, fonts)
├── index.html            # The main landing page / Home page
├── .hintrc               # Webhint configuration file
└── Basic.txt             # Basic text configurations or notes


🛠️ Technologies Used
HTML5: Structure and content of the web pages.

CSS3 / JavaScript: (Located in the wwwroot/ folder) Styling and interactivity.

Claude AI / Pollinations: Integrated for the backend AI features (Chat, Code, Image).
